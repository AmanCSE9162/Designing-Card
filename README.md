# 🌊 Nature Card – HTML & CSS

A simple and clean **Nature Card UI** created using **HTML and CSS**. The card displays a beautiful lake image along with category tags, a title, description, and a "Read More" button.

## 📌 Project Preview

The card contains:

* 🖼️ Nature/lake image
* 🏷️ Category tags – `Nature` and `Lake`
* 📝 Title – `LIO`
* 📄 Description text
* 🔘 Read More button
* 🎨 Rounded corners and clean styling

## 🛠️ Technologies Used

* **HTML5** – For creating the structure of the card
* **CSS3** – For styling, spacing, colors, borders, and layout

## ✨ Features

* Simple and beginner-friendly design
* Responsive card layout
* Rounded image and card corners
* Category badges
* Styled button
* Clean and minimal UI

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Use **Live Server/Live Preview** to view the card in your browser.

## 🎯 Purpose

This project was created to practice **HTML and CSS fundamentals**, including:

* HTML structure
* CSS styling
* Box model
* Border radius
* Padding and margins
* Buttons
* Image styling
* Basic UI design
